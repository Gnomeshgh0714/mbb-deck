# BD 材料页：固定页包与组件模式

面向 BD（商务拓展/提案）类 deck 的两类资产：**固定页包**（内容固定的成品页）与**组件模式集**（从成熟 BD 提案提炼的版式模式）。固定页解决「每次都一样」的公司介绍部分，组件模式解决「每次不一样」的论证部分。

## 1. 固定页包（assets/templates/bd/）

7 页成品页，命名与占位符见 [assets/templates/bd/README.md](../assets/templates/bd/README.md)。使用规则：

- **机械还原原则**：7 页均为源 pptx 的机械还原（原色、原渐变、原圆角、原图标，布局全行内样式零类名冲突）。不对固定页做品牌蓝映射或版式重排；`bd-slide` 前缀页被 `check_deck.py` 豁免品牌规范扫描（标题门/禁用模式/粗圆角），按源文件还原优先
- **识别 BD 任务**：用户说「做 BD 材料 / 提案 / 竞标 / 商务拓展材料」，或给出的参考 PPT 含这 7 页同款页面时，先声明固定页包可用，让用户点名取用；不整包强塞
- **模板页（目录页/章节页/优势总览页）**：替换占位符后拼入——目录条目 `{{TOC_ITEM_1..3}}`（固定 3 条，不自动扩展）；章节页 `{{SECTION_NO}}`/`{{SECTION_TITLE}}`；优势总览页 `{{ADV_COUNT}}`/`{{CLIENT_NAME}}`/`{{ADV_n_TITLE}}`/`{{ADV_n_DESC}}`。目录条目、章节划分跟随本次 Storyline，不默认沿用三章结构
- **固定页（公司名片页/智库背书页/国资经验页/服务优势页）**：内容原样拼入，不改数字、口径、来源注；无占位符、无页码占位，页码沿用目标 deck 自身机制。数字与事实以页内文案为准，不得「顺手更新」
- **页眉组**：固定页左上角「更懂国资要求 · 序号」栏目标签（行内样式形状组）。若本次 deck 未采用「三大优势」章节结构，可按形状定位整组移除，不算保真失败
- 拼装后全文检索 `{{` 确认无占位符残留；最终单文件交付必须把 `img/` 图片 base64 内嵌
- 固定页内容的事实更新（新数字、新案例、新活动照片）只由用户提供的新材料驱动，不由 skill 推测

## 2. BD 组件模式集

从成熟 BD 提案（27 页完整版）提炼的版式模式。这些是**可自由组合的原语**，不是封闭模板；与 [visual-language.md](visual-language.md) 的语法配合使用。

### 2.1 Subtitle 变体

| 模式 | 结构 | 适用 |
|---|---|---|
| 编号标签式 | 深蓝编号块 `01` + 粗体短标题 + 灰色描述行 | 三个并列卖点（如优势总览页） |
| 视角标签式 | 居中实色小色块标签，等宽等高 | 多视角审视同一对象（市场/集团/自身） |
| 阶段标签式 | 顶部时间轴标签 + 阶段列 | 短期/中期/长期、三步走 |
| 行首窄列标签 | 左侧窄灰列放模块名，右侧放内容 | 难点/实践/建议式三段对照 |
| 栏目标签条 | 深蓝圆角小条 + 线性图标 | 卡片组标题（智库背书页三栏） |

### 2.2 箭头与流向

- **三栏对照**：难点 -> 实践 -> 建议 的阅读方向由列序承担，列间不加装饰箭头，用列头标签与共享行网格对齐表达
- **阶段推进**：阶段列之间用细连接线或箭头，方向连续、节点等距；「阶段目标」与「服务内容」共享行网格
- **归组到结论**：三栏底部的共同结论条（如「通过X，实现Y」）用全宽浅蓝条收口，视觉上接收上方三栏

### 2.3 text box 构图

- **数字名片**：大数字（44-48pt）+ 小标签（16pt）成组；深蓝块白字、浅底块深蓝字；块可错落拼贴但共享网格感（公司名片页）
- **团队卡**：人名标签（小色块）+ 履历文本块，等宽列阵；履历中的机构名保留原文
- **三栏矩阵**：等宽三列 + 共享行网格，对应行等高；列头用 Subtitle 变体区分角色
- **阶段矩阵**：阶段标签列 × 内容行的表格化构图；行首标签窄列，内容格等高
- **页底结论条**：全宽浅蓝圆角条，一句话承接整页三栏的输出
- **封底组件**：官网/电话/地址/邮箱/公众号四件套，居中排布，配品牌色块；BD deck 收尾页可直接复用此组件

### 2.4 BD 特有构件

- **栏目页眉**：左上角小编号块 + 章节名的栏目标签组，让固定页群在视觉上归属同一章节
- **案例对标卡**：转型前（灰，问题语义）-> 转型举措（蓝，行动语义）-> 结果（深蓝，成果语义）的纵向演进卡；多个案例卡并列时共享行网格
- **logo 墙**：白色小格 + 灰底容器 + 流式换行；格内 logo 等高约束，不拉伸变形

## 3. 何时扩展本文件

- 新的 BD 材料出现跨页稳定的版式模式（≥3 次验证）时，按上表格式补充模式行，注明来源场景
- 固定页内容需更新时，直接改 `assets/templates/bd/` 对应文件并在其 README 登记，不在本文件重复内容
