# Strict Conversion：逐页 dummy 保真契约

本文件只用于已有 PPT、逐页 dummy 或明确页级结构的严格转换。目标不是重新策划内容，而是在保留原页信息与分析关系的前提下升级为品牌蓝灰、固定 16:9 翻页 HTML。

## 1. 先建立源页面清单

每页渲染前盘点并在内部对应：

- Action Title、Subtitle、正文、引用、脚注、来源和页码
- 数字、单位、时间、口径、系列与图例
- 图表类型、方向、排序、轴、刻度、年份和可见数据标签
- 箭头、括号、差值线、call-out、高亮框的文字、锚点和相对位置
- Logo、图片、图标及其对象归属
- 平行、因果、流程、汇聚、对比等空间关系

只读取幻灯片实际可见内容。隐藏、越界、备注或制作过程对象默认排除。

## 2. 可以改变与不得改变

可以改变：

- 品牌配色、字体、线条粗细、间距和细节精度
- 在不改变对象关系的前提下，小范围移动元素以消除溢出或重叠
- 将可见资产提取并内嵌为 base64 / SVG，使 HTML 保持单文件

不得擅自改变：

- 页数、页序、页面边界和内容归属
- 可见文字、数字、单位、来源及名称
- 图表类型、方向、排序、轴、图例和分析标注构图
- call-out 的锚点、括号或差值线的起点与终点
- Logo、图片、图标及其承担的识别或举证作用

如果源页面已经清楚表达结论，默认“画得更好”，不“换一种说法”。

## 3. 图表保真

### 比较柱形

- 共享尺度的比较柱保留共同基线
- 差异标注直接连接对应柱或柱顶，不能移到图表下方成为孤立结论条
- 比例括号必须同时落到比较起点和终点，标签紧邻连接结构

### 折线图

- 保留解释趋势所必需的轴、刻度、年份、系列、端点标签和 call-out
- call-out 保留 `message`、`anchor`、`placement`；不得变成图下注释
- 数据标签采用错层、水平错位或引导线避让，不压在线上或互相遮挡

### 数据完整性

重画后逐项核对源页面清单。源文件数据无法可靠读取时，保留可见数值与视觉关系并报告限制；不得自行补数，也不得静默删除。

## 4. 几何与字体

- Action Title 与正文主画幅使用相同左右边界，固定预留两行区域
- 主体正文默认 14pt；文字特别少可用 16pt，特别多可用 12pt
- 引用正文使用斜体
- 平行比较共享同一行网格：对应框逐行等高、同基线、同间距
- 非平行模块同处一个水平画幅时，也检查并尽量对齐图表轴线、案例框或结论带的主要底线；不得把 Footnote 或页码误作正文基线
- 同一图中的同层级数据标签保持一致字号和字重；极小柱的标签移到柱外，不单独缩小
- 内容较短的一侧保留空白，不能自行缩短框高破坏平行关系
- 非预期重叠必须修复；不能依靠缩字或删除标签掩盖问题

## 5. 资产与去重

- 可见 Logo、图片、图标必须提取并内嵌；无法提取时停止静默交付并说明
- 同一紧密模块内，同一实体只保留一个主标签
- 不新增源页面没有的解释性文字来填空，也不因新增标题造成名称重复

## 6. 逐页验收

最终渲染必须与源页面逐页并排检查：

1. 页数、页序与页面边界一致
2. 可见文字、数字、单位、来源和资产齐全
3. 图表结构、轴、数据标签和标注锚点齐全
4. 平行元素逐行对齐，Action Title 与主画幅同宽
5. 主体正文以 14pt 为默认，引用为斜体
6. 无非预期重叠、裁切、单字孤行和无法解释的重复

任何一项失败都先修复，再交付。
