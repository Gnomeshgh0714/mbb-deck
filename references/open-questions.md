# 当前状态与待讨论项

更新时间：2026-08-31（v1.1 最小收敛）

## 本轮已收敛

- 已有 PPT、逐页 dummy 或明确页级结构默认进入逐页转换模式，严格保留页数、页序、页面边界和内容归属
- 只有用户明确要求重组、精简、合并或重写 Storyline 时才允许跨页调整
- 当前只做固定 16:9 翻页 HTML
- Intake 不再是每次必填表单；信息足够直接推进，关键歧义才追问
- 12 类 data-shape 保留为内部参考词汇，不再是封闭模板库
- 不强制输出路由 JSON 或逐页相邻版式辩护
- 内容重组模式下，Action Title 可以基于证据提炼；逐页转换模式保留输入标题，不得自行改写
- Subtitle 以 14pt 为默认值，通常不超过 18pt
- 左上栏目标签默认不使用，但是否完全禁用仍待跨页面验证
- 空白率不设固定百分比；图表可成为页面主体，但必须被 Action Title 或标注解读
- QA 文档只声明当前静态脚本真正能检查的项目，视觉质量必须查看最终渲染
- PPTX 与历史 archive 不进入本版正式交付包
- 比较柱形保留共同基线；差异线、比例括号和 call-out 保留源对象、锚点与相对位置
- 严格转换默认保留成熟图表的类型、方向、排序、轴、标签、图例和分析标注
- Action Title 与正文主画幅共用左右边界；平行比较共享逐行等高的共同网格
- 主体正文默认 14pt，按内容量在 12–16pt 内调整；引用正文使用斜体
- 可见 Logo、图片和图标必须提取并内嵌；紧密模块内不新增重复名称
- 非预期重叠为 Blocker，必须在最终渲染中修复
- 同一图中的同层级数据标签保持一致字号与字重；极小柱采用外置标签，不单独缩小数字
- 同一水平画幅中的非平行模块也优先寻找共同的主要底线；图表轴线、案例框或结论带在不破坏结构时对齐，Footnote 与页码不参与

## 仍待校准

- 标题区、正文起点、页边距和 Footnote 的最终几何
- Action Title 使用纯黑还是品牌近黑
- Footnote 最终字号与位置
- 灰色问题区的准确色阶
- number ball、icon、暖黄色和动画的使用边界
- 左上栏目标签是否存在少量合理场景
- 多页 Storyline 在不同材料上的稳定性
