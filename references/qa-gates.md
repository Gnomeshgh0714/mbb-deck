# QA Gates：交付前检查

代码检查与视觉检查互相补充。只有能被当前工具可靠判断的项目才称为机械检查；taste、论证强度和视觉重心必须由人或模型查看最终渲染结果。

## Gate 1：逻辑

- Action Title 是否回答页面问题，证据是否支撑标题
- 页面是否只有一个主要 takeaway
- 问题、路径、结果和箭头关系是否清楚
- 多页 deck 的 Action Title 连读后是否形成连续论证

## Gate 2：内容与数据

- 人名、公司名、数字、单位、时间和来源与素材一致
- 没有把内部草稿、制作说明或待讨论文字放入面向受众的页面
- 没有发明事实；改写没有改变原意
- 假设与事实分开，口径冲突不制造折中数字
- 来源位于左下安全区，页码位于右下
- 除引用或必须保留的正式文本外，不以中文句号结尾
- 逐页转换已核对源页面清单：图表轴与标签、标注锚点、Logo / 图片 / 图标均无遗漏
- 没有由重排新增的重复名称、重复标签或重复数字

## Gate 3：容量预判

- 写 HTML 前判断内容能否装入候选结构
- 超容时按“精简表达、调整宽度或结构、拆页、最后才缩字号”的顺序处理
- 正文不得低于 Foundation 下限硬塞

## Gate 4：结构与几何

- 画布为 1600×900，整页等比缩放，页面和内部容器无滚动条
- 固定两行标题区存在；正文起点不随标题行数变化
- Action Title 与正文主画幅共用左右边界，并充分利用整行宽度后再换行
- Action Title 最多两行
- 平行模块共享同一行网格：对应标题、导语、正文行和结果区逐行等高并水平对齐
- 非平行模块处于同一水平画幅时，已检查可共享的主要底线；图表轴线、案例框或结论带在合理条件下形成稳定的共同视觉基线
- 无遮挡、越界、裁切、意外换行和单字孤行
- 无文字—文字、文字—数据标签或文字—关键图形的非预期重叠
- 图表标签、连接器和方向性造型与实际逻辑一致

## Gate 5：视觉

- Action Title 为 24pt、黑色或近黑色、完整句子
- Subtitle 通常不超过 18pt，同层级一致；14pt 为默认值
- 主体正文默认 14pt；只有内容明显稀疏或密集时才使用 16pt 或 12pt
- 引用正文使用斜体，并与普通分析文字明显区分
- 灰色与蓝色承担明确语义，没有机械蓝化所有区域
- 留白服务层级和重心，不用固定百分比判断好坏
- 页面主要视觉语言一致，平行模块不混用不同组件
- 同一图中的同层级数据标签字号、字重与数字格式一致；极小图形的标签通过外置或引导线处理，不靠缩小字号
- 页面既不过度朴素，也不堆叠无意义装饰

## Gate 6：交付

- HTML 单文件可打开，资源路径有效
- 多页 deck 的翻页控件、键盘、滚轮和触控入口可发现且可用
- `prefers-reduced-motion` 与打印模式显示完整终态
- 动效一次性、无循环、无弹跳
- 最终 HTML 与预览图来自同一版内容和几何
- 逐页转换的最终渲染已与源页面逐页并排复核，不只检查 HTML 自身
- 保留旧版本，除非用户明确要求覆盖

## 当前机械检查的真实范围

`scripts/check_deck.py` 是无需浏览器的静态初筛，目前只检查：

- `<div>` 开闭数量
- HTTP 外部资源引用
- 1600×900 与 `overflow:hidden` 声明是否可检出
- `.slide`、页面标题、DOCTYPE 与 HTML title 的基础结构
- 多页 deck 是否存在可见导航和滚轮监听
- emoji、`backdrop-filter`、循环动效和较厚圆角等静态模式

它**不检查**真实 bounding box、标题实际行数、平行模块几何、空白率、中文断行、元素遮挡或页面视觉重心。以上项目必须查看最终浏览器渲染；静态检查通过不等于视觉 QA 通过。
