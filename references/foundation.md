# Foundation：已确认规则与当前默认值

本文件区分“已确认硬规则”和“当前校准默认值”。只有前者可作为 P0；默认值可在后续讨论中调整。

## 1. 产品边界

### 已确认

- 当前只做固定 16:9 翻页 HTML
- 逻辑画布固定 1600×900，浏览器中整页等比缩放
- 每页单屏，无页内滚动；长页以后有需求再做
- HTML 的动画和交互可以超过 PPT 能力，但必须服务逻辑和阅读顺序

## 2. 字体层级

浏览器按 96dpi 映射：`1pt = 1.3333px`。

| PPT 字号               |  HTML 等效 | 状态       |
|------------------------|-----------:|------------|
| Action Title 24pt      |       32px | 已确认     |
| Subtitle 通常 ≤18pt    |      ≤24px | 已确认     |
| 正文默认 14pt          |    18.67px | 已确认     |
| 正文例外 12–16pt       | 16–21.33px | 已确认     |
| 当前 Footnote 9pt      |       12px | 待确认例外 |

### Action Title

- 页面级标题固定 24pt
- 使用黑色或近黑色；不得用蓝色把同一句拆成第二层强调
- 一般是一个完整句子，不把标题设计成两条独立 message
- 固定预留两行高度；一行标题也不得让正文上移
- 标题从固定区域顶部对齐，最多两行；超过两行优先改写
- 标题区与正文主画幅使用同一组左右边界，不为标题设置更窄的 `max-width`
- 先充分利用整行宽度再自然换行；避免为了防拆词而过早把较长词组整体推到第二行
- 当前几何默认：标题区 `top:72px; height:84px`，分隔线 `top:176px`，正文 `top:206px`
- 几何值尚未最终确认，但“固定两行区域、正文起点不跳”是硬规则

### Subtitle

- Subtitle 指页面内部不同模块或框的核心 message，不是 Action Title 下方的副标题
- 字号通常不超过 18pt；14pt 为当前默认值，不是固定值
- 同一页同层级 Subtitle 使用相同字号；模块 message 与图表小标题可用字重、颜色或位置区分层级
- 同层级 Subtitle 必须同构、等高、对齐
- Subtitle 的形状可变化，见 `visual-language.md`

### 正文与脚注

- 主体正文默认 14pt；文字明显较少时可放大到 16pt，明显较多时可缩小到 12pt
- 内容太多时先调整结构、宽度和文本框；内容重组模式可改写或拆页；逐页转换模式不得擅自删改，12pt 仍放不下时报告超容
- 正文不得大于 16pt，一般不得小于 12pt；Footnote、坐标轴、图例和极小辅助说明不属于主体正文
- 引用正文统一使用斜体，以区别于分析正文；署名紧随引用并形成清晰层级
- Footnote 属于例外层级，可小于 12pt；具体字号与位置仍待后续校准

## 3. 中文排版纪律

### 已确认

- 除引用或必须保留的正式文本外，PPT/HTML 页面文案不以中文句号结尾
- 不出现只有一个汉字或一个标点的孤行
- 标题、标签和横幅若设计为单行，不能意外换行
- 出现孤行时，处理顺序为：精简文案 → 调整文本框或结构 → 最后才缩小字号
- 平行对象必须在位置、尺寸、标题基线、正文起点、内边距和视觉重量上保持对称
- 逻辑平行必须转化为共同几何网格：对应行共享顶部、底部和高度，由内容较多的一侧决定统一行高，不能各自随内容自动伸缩
- 同一水平画幅内，即使模块内容或结构不平行，也先寻找可共享的主要视觉基线；在不破坏信息结构、不制造不合理留白时，优先对齐图表轴线、案例框底边或结论带底边。Footnote 与页码不参与正文基线
- 文字、数字和关键图形不得发生非预期重叠；容器内有意放置不算重叠，但任何互相遮挡或影响辨认的叠加都必须修复

### 文本框容量预判（必须执行，算法为参考）

溢出与重叠大多源于「目测能放下」。写入任何文本框前必须先算预算：

- 字符宽度：CJK 与全角标点 = 1 em；ASCII 字母数字 ≈ 0.52 em；空格 ≈ 0.3 em（em = pt × 1.3333px）
- 行高：雅黑类字体自然行高 ≈ 1.32 em；PowerPoint 的多倍行距在 1.32 基数上再乘（HTML 的 line-height 是直接倍数，两边语义不同，勿混用同一套数字）
- 预判：Σ(每段预计行数 × 行高) + 段间距不超过框高，且文本底缘与下一元素保留可读净距
- 预算不足时按既定顺序处理：精简文案 -> 加高/加宽文本框 -> 调结构；禁止硬塞后依赖「文本框不裁切」侥幸
- 多段落文本框必须显式声明段间距；默认段距足以把最后一行推出窄框
- 预判后仍必须以浏览器最终渲染为准，检查真实断行、溢出和遮挡

## 4. 颜色语义

### 已确认

- 品牌蓝是核心品牌色，但不意味着所有元素都蓝化
- 灰色用于问题、现状、约束、转型前或基准状态
- 品牌蓝用于主张、行动路径、解决方案和主要强调
- 浅蓝或浅灰用于辅助背景、解释区和低层级结构
- 颜色必须承担逻辑功能，不能只为装饰换色

### 当前品牌蓝

- 深蓝 `#0A3D8A`
- 主蓝 `#0E58C4`
- 中蓝 `#4A8EF2`
- 浅蓝背景可从以上色值低饱和或低透明度派生

灰色色值、暖黄色是否保留、其他语义色的使用范围尚未最终确认。

### 渐变的使用（2026-09-02 放宽）

- 品牌色系内的**方向渐变**允许使用：同一色相两档之间（如深蓝→主蓝）、白→浅灰的卡片底、或亮化/暗化派生色之间；角度以 45°/135°/180° 为宜
- 允许的典型用法：卡片渐变底与渐变描边（双层 background + background-clip）、标签条渐变、数字/图形点缀的 135° 深蓝渐变
- 渐变必须仍在品牌色系或源素材色系内，不得跨色相拼接出彩虹效果（§7 的「彩虹渐变」禁令不变）
- 图标优先使用 SVG 矢量（语义化小图标，见 visual-language.md「图标」节），不用 emoji 代替

### 固定页与严格转换的颜色例外

- BD 固定页包（`assets/templates/bd/`，`bd-slide` 前缀页面）是** pptx 机械还原**：使用源文件的原始色值、渐变与圆角（如 `#629DD1` 系主题蓝、`#242852` 深藏蓝、45° 对角渐变描边、16% 圆角标签），**不做品牌蓝映射、不改源形状属性**
- 严格转换模式同理：可见元素的颜色、渐变、圆角属于源页面内容，按源文件还原；本节品牌蓝规范与 §7 禁用模式不适用于固定页与严格转换的源原生属性

## 5. 页面骨架

### 已确认

- 页面底部通常不加贯穿横线
- 右上角不放无业务意义的灰色英文标识
- 来源放左下，页码放右下
- 正文区域必须服从固定标题区，不因标题一行或两行改变起点

### 当前校准默认

- 左右安全边距：72px
- 顶部品牌细线：8px
- 左上栏目标签：默认不使用；仅在它承担真实章节导航或语境作用时使用
- Footnote：左 72px、底 28px、9pt
- 页码：右 72px、底 25px、10pt
- 模块内内容垂直分布必须均衡；当 flex 容器拉伸填满可用空间但内容不足以铺满时，内容应视觉居中而非贴顶排列

这些数值用于保证当前样页稳定，后续可统一调整。

## 6. 动效

- 可以使用一次性错峰出现、路径推进和结果揭示
- 禁止循环、弹跳、炫光和与逻辑无关的运动
- `prefers-reduced-motion` 和打印模式必须直接显示终态

## 7. 禁用模式

以下模式默认避免。是否构成 blocker 取决于是否违反可读性、可编辑性、事实准确性或用户明确要求；不能因为一次案例不好看就机械封禁全部变体。

**适用范围**：本清单约束 skill 常规生成页。固定页（`bd-slide` 前缀）与严格转换中的**源文件原生属性**（源 PPT 的圆角、渐变、配色等）不受本清单限制，按源文件还原优先。

- 蓝紫霓虹 / 赛博辉光 / 彩虹渐变
- 全 deck 大面积深色背景
- 厚圆角卡片 / 玻璃拟态（backdrop-filter）/ App 仪表盘风
- 通用商务人像 / 握手 / 机器人 / emoji
- 大话题标题旁摆无关图标
- 一页多个隐喻
- 海报式小字堆叠
- 把文字密集的页拍平成图片
- 装饰性竖线 / 过度设计的"AI 感"卡片
- 没有 Action Title 解读、只陈列图表而不说明含义的页面
