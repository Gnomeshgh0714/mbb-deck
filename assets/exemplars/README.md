# 校准范例目录

本目录存放校准范例（exemplar）HTML，是 skill 三层质量体系中的「范例校准层」：规则保正确性下限，范例带观感上限。

**公开版仓库不附带范例文件**——范例取自内部业务案例，属内部资产，不随公开仓库分发。

## 使用规则（对范例文件生效）

- 范例只用于学习比例、层级、留白、语义和 taste，不是必须照抄的模板
- 不复用范例中的事实，不把范例形状变成强制模板
- 支持附件 / 知识库的平台（OpenAI Custom GPT、WorkBuddy 等）部署时，请把范例 HTML 一并传入，否则输出观感落回规则下限水平

## 私有部署

内部使用或私有部署时，将范例 HTML 放入本目录即可，skill 与可移植版均按本目录定位范例。
