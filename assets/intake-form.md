# 输入解析参考

本文件帮助 Skill 从复杂材料中提取信息，不是每次使用前必须让用户填写的表单。

## 默认交互

0. 先识别是逐页转换还是内容重组；已有 PPT、逐页 dummy 和明确页级结构默认逐页转换
1. 输入已包含主题、受众或明确内容时，直接推进并回显必要假设
2. 缺失信息可以低风险推断时，采用合理默认，不暂停工作
3. 只有受众、业务含义、关键数字口径或交付范围的不同答案会实质改变结果时才追问
4. 完全没有材料时，只索取材料与预期用途，不一次性抛出长表单

## Deck 级信息

| 字段 | 作用 | 缺省处理 |
|---|---|---|
| 主题 / 中心论点 | 确定 Storyline | Skill 从材料提炼候选 |
| 受众与场景 | 决定表达角度 | 默认按管理层汇报理解，并在交付说明中披露 |
| 篇幅 | 控制信息密度 | 由内容决定最小够用页数 |
| 材料 | 提供事实与证据 | 无材料时向用户索取 |
| 口径与假设 | 控制事实边界 | 不猜测关键数字，必要时追问 |

交付形态固定为 16:9 单文件 HTML，不重复询问。

## BD 固定页包（BD / 提案 / 商务拓展类任务）

识别为 BD 类任务时，主动向用户报出固定页包页面名，由用户点名取用：

| 页面名 | 类型 | 需要用户提供 |
|---|---|---|
| 目录页 | 模板页（每次调整） | 3 条目录条目 |
| 章节页 | 模板页（每次调整） | 章节编号（两位数）与章节名 |
| 优势总览页 | 模板页（每次调整） | 客户名、优势条数（默认 3）、每条优势的标题与描述 |
| 公司名片页 | 固定页（直接可用） | 无（原样拼入） |
| 智库背书页 | 固定页（直接可用） | 无（原样拼入） |
| 国资经验页 | 固定页（直接可用） | 无（原样拼入） |
| 服务优势页 | 固定页（直接可用） | 无（原样拼入） |

- 固定页与模板页均为 pptx 机械还原（原色/原渐变/原图标，不做品牌化改写）；固定页内容不改写、不"顺手更新"数字，更新只由用户提供的新材料驱动
- 固定页无占位符、无页码占位（页码沿用目标 deck 自身机制）
- 拼装与占位符规则见 [assets/templates/bd/README.md](templates/bd/README.md)，组件模式见 [references/bd-pages.md](../references/bd-pages.md)

## 可选编号结构

用户可以用编号显式标记内容层级：

- `1` = Action Title
- `1.1`、`1.2` = 同级 Subtitle
- `1.1.1`、`1.1.2` = 对应 Subtitle 的证据或下一级内容

编号帮助识别层级，最终页面不显示。若用户没有编号，Skill 从自然语言、表格、PPT 或截图中自行识别。

## 自然语言与参考材料

- “主标题 / 核心主题”通常映射为 Action Title，但允许在不改变事实含义的前提下优化为结论句
- “第一部分 / 左侧 / 中间 / 右侧”表示内容分组或原版偏好，不自动成为新页面的强制位置
- 在逐页 dummy 中，页面边界和内容归属是硬边界；方位可以重画，但内容不得移到其他页
- 参考页中的箭头、括号、色块和空间方向先按业务逻辑理解，再决定是否保留或重画
- PPT 中的制作说明、讨论记录、待补内容和作者备注不属于面向受众的可见文案

## 诚实规则

- 关键数字尽量保留单位、时间和口径；缺失且会影响结论时请求确认
- 假设显式标注，不与事实混排同权
- 来源逐页保留
- 不发明数字、案例、年份、引用或业务结果
