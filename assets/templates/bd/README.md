# BD 固定页包（Boilerplate Pack）

BD（商务拓展）材料的固定页面资产，共 7 页，分两类：

- **模板页（每次要调）**：替换占位符后拼入
- **固定页（直接可用）**：内容与本公司强绑定，原样拼入，不改内容

## 生成方式：pptx 机械还原（2026-09-02 重做）

现行版本以源 PPT 的 XML 为唯一依据，逐形状机械转换为 HTML（1600×900 画布，1in=120px）：

- 位置、尺寸、字号、颜色、渐变、圆角、图片**全部按源文件还原**，不做品牌蓝映射、不简化图标、不重排版式
- 源 PPT 主题色原样保留（`#629DD1` 系主题蓝、`#242852` 深藏蓝、`#30356D` 等），原 freeform 图标还原为 SVG path
- 颜色与圆角属**源文件原生属性**，不适用 foundation.md 的品牌蓝规范与禁用模式清单（见其「固定页与严格转换的颜色例外」节）
- 2026-08-31 第一版曾把源色统一映射为品牌蓝并简化图标，已废弃；禁止再对固定页做品牌化改写

## 占位符约定

| 占位符 | 位置 | 说明 |
|---|---|---|
| `{{TOC_ITEM_1/2/3}}` | 目录页 | 3 个条目文本，53.3px 加粗单行；过长会溢出，需精简。源 PPT 即 3 条，**不自动扩展**；如需增删条目要复制「编号圆 + 文本」形状组并重排 |
| `{{SECTION_NO}}` | 章节页 | 章节编号，两位数（01/02/03…），133.3px 主蓝 |
| `{{SECTION_TITLE}}` | 章节页 | 章节名，60px 深藏蓝，带 10px 字距；与目录条目保持一致 |
| `{{ADV_COUNT}}` | 优势总览页 | 优势条数（默认 3），160px 大数字 |
| `{{CLIENT_NAME}}` | 优势总览页 | 客户名，嵌入优势句式「…独特优势，本公司期待成为{{CLIENT_NAME}}长期产业投资伙伴」 |
| `{{ADV_n_TITLE}}` / `{{ADV_n_DESC}}` | 优势总览页 | 第 n 条优势的标题（40px 加粗）与描述（33.3px），固定 3 条 |

拼装后必须全文检索 `{{`，确认无残留占位符。

## 拼装方式

每个模板文件由两段构成：

1. `<style id="bd-{name}-css">` 样式块：**必拷**，整块并入目标 deck 的 `<style>` 区；同一 deck 内多次使用同款页（如多个章节页）时只拷一次
2. `<!-- 拼装起点 -->` 到 `<!-- 拼装终点 -->` 之间的 `<section class="slide bd-slide bd-{name}">`：**必拷**

注意：

- `bd-slide` 类名双重作用：供 base-deck 的翻页/缩放逻辑识别 `slide`，同时让 `check_deck.py` 跳过品牌规范扫描（标题门、禁用模式、粗圆角检查）——机械还原页按源文件优先，豁免是**有意的**
- 页面内布局全部行内样式，仅 `bd-slide bd-{name}` 一个类选择器，与任何 deck 的既有类名零冲突
- **无 `{{PAGE_NO}}` 占位符**：原 PPT 布局的页码占位为空，未还原；页码沿用目标 deck 自身的页码机制或省略
- 左上角「更懂国资要求 · 序号」页眉组（公司名片/智库背书/国资经验三页）现为行内样式形状组；若本次 deck 未采用「三大优势」章节结构，可按形状定位整组移除，不算保真失败
- 模板里 `img/` 为相对路径引用；**最终交付的单文件 HTML 必须把图片 base64 内嵌**（`build_bd_demo.py` 的三种引用形式替换逻辑可参考）
