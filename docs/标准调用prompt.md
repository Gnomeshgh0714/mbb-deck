# mbb-deck 标准调用 Prompt（员工使用）

**前提**：所在项目或全局已安装 mbb-deck skill（安装方式见仓库 README）。

**用法**：把模板整段复制给 Claude，只改尖括号 `<>` 里的内容，固定部分一字不动。格式与自己平时口述需求的方式一致——主标题、分板块、每块讲什么，顺着写下来就行。

---

## 模板（一页一段，页数按需增减）

```
请根据我给你的内容，用 mbb-deck skill 输出一版<PPT / HTML>，整体颜色以深浅不一的蓝色为主。

第一页：主标题也就是核心主题是"<这页的结论句，想清楚再写，做好后逐字保留>"；主体区域分为左中右三大板块，左边放"<板块小标题>"，具体内容是<背景、问题或现状，自然描述>；中间主要放三个内容，第一部分核心内容是<小标题>，具体包括<支撑内容，数字带单位、时间、口径>；第二部分核心内容是<小标题>，具体包括<支撑内容>；第三部分核心内容是<小标题>，具体包括<支撑内容>；右边主要放三个内容，第一部分是<结果/数字>；第二部分是<结果/数字>；第三部分是<结果/数字>；本页资料来源：<来源行，含数据注释>。

第二页：主标题是"<……>"；主体区域……（同上，按这页内容调整板块）
```

- 方位词（左中右 / 左右 / 上下）和板块数量按内容定，不必凑满三块三段
- 动手前 Claude 会先弹出点选表单（交付形态、篇幅、受众，已写明的不再问）并附一屏「开工简报」（中心论点、逐页结构、待确认项），选完确认后再做

结尾固定加两行：

```
这版给<谁>看，场合是<什么场合>，希望对方<做出什么决策>；关键数字我都带了单位、时间和口径，缺的请直接来问我，不要自行补。
```

## 简版（只有一堆材料，还没想好结构）

```
请根据我给你的内容，用 mbb-deck skill 输出一版<PPT / HTML>（蓝灰）。
材料：<粘贴材料正文，或写文件路径>
这版给<谁>看，希望对方<做什么决策>。
先弹点选表单（篇幅、受众等没写明的项）并出开工简报让我确认，确认后再做。
```

## 填好的样子（虚构示例，仅演示格式）

> 请根据我给你的内容输出一版ppt，整体颜色以深浅不一的蓝色为主，主标题也就是核心主题是"渠道变革：线上线下融合叠加渠道精简、效率提升与会员运营，让公司在转型首年实现收入利润双增长，形成可复制的转型路径"；主体区域分为左中右三大板块，左边放"转型前的渠道状况…"，具体内容是核心业务依赖线下经销渠道，伴随客流下滑，门店面临经营压力；同时，线上线下价格不统一，存在渠道冲突，会员体系相互割裂。中间主要放三个内容，第一部分核心内容是渠道精简，具体包括将三级经销层级整合为两级，统一线上线下价格体系；第二部分核心内容是效率提升，具体包括上线数字化订货与库存一体化平台，订单交付周期从 14 天缩短至 5 天；第三部分核心内容是会员运营，具体包括打通各渠道会员体系形成统一会员资产，会员复购率从 22% 提升至 35%。右边主要放三个内容，第一部分是 2025 年渠道收入同比增长 18%+；第二部分是单店运营成本下降 30%+；第三部分是形成可复制转型模板并已在 3 个大区推广。

---

## 三条要点（最容易踩坑）

1. **数字三件套**：关键数字都要带单位、时间、口径（"2025 年渠道收入同比增长 18%+"，而不是"收入增长很快"）。缺了 Claude 会停下来问，来回一轮反而慢。
2. **主标题是逐字保留的**：`主标题也就是核心主题是"……"` 这一句想清楚再写，它就是每页的结论，skill 不会替你改。
3. **来源逐页给**：每页结尾的 `本页资料来源：<……>` 不要省，没有来源的数据页会被退回补。
